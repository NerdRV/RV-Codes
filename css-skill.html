📖 My Journey

I started learning CSS in 2023 — right alongside HTML, because what's a skeleton without some style? 💙 My first CSS moment was changing a heading color and thinking "wait… I can make it look however I want?!" — and I was instantly obsessed.

I went from basic colors and fonts to understanding the box model — how every element has margin, border, padding and content. Then came Flexbox, which completely changed how I thought about layouts. Then CSS Grid, then animations and hover effects.

Today, almost every visual effect on this portfolio — the glowing cards, the neon animations, the star field, the particle effects — is CSS working its magic. It's honestly my favourite part of coding! ✨

💻 Sample Code I Can Write

style.css
/* CSS Variables — my favourite trick 💙 */ :root { --blue: #264de4; --glow: 0 0 20px rgba(38,77,228,.6); } /* Glowing card with hover effect */ .card { background: linear-gradient(135deg, #060f2a, #0a1a3a); border-radius: 16px; padding: 24px; transition: transform 0.3s, box-shadow 0.3s; display: flex; align-items: center; gap: 16px; } .card:hover { transform: translateY(-6px); box-shadow: var(--glow); } /* Keyframe animation */ @keyframes float { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-10px); } }
