📖 My Journey

I started learning JavaScript in 2023 — after HTML and CSS felt comfortable. My first JS moment was using document.getElementById() to change text on a page and watching it update instantly. That feeling of "the page is REACTING to me" was unreal. 🤯

I learned variables, loops, and functions first — the basic building blocks. Then I discovered DOM manipulation, which lets JavaScript control everything you see on a webpage. Then came events — making things happen when a user clicks, types, or moves the mouse.

Today, JavaScript is how I bring all my projects to life. HyphenBot, Star Catcher, the Quiz Maker, the Study Buddy — every single one runs on JavaScript. It's the most powerful tool in my toolkit right now! ⚡
