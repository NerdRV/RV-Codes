📖 My Journey

I started using GitHub in 2026 — and it completely changed how I think about coding. Before GitHub, my projects lived only on my computer. Now they're live on the internet for anyone to see, use, and learn from.

My first ever push was terrifying — typing git push and watching my code go live felt unreal. I learned how to create repositories, write commit messages, and use GitHub Pages to host this very portfolio for free!

GitHub is also where the entire developer world collaborates — open source projects, code reviews, issue tracking. I'm just getting started, but I'm already hooked. Every commit is a little piece of my coding journey, permanently saved. 💜
